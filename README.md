# Smart-Protective-Relay-with-Integrated-Power-Quality-Analysis-and-Energy-Metering
This low-cost ESP32 platform integrates power monitoring, energy metering, and protection. It tracks voltage, current, power, frequency, and power factor. To ensure electrical safety, it detects overvoltage, undervoltage, and overcurrent faults, instantly disconnecting the load via a relay to protect appliances.
